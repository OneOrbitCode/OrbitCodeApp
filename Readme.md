# OrbitCode v1.1.1

Your AI-powered desktop companion. Ask questions, capture your screen, dictate by voice — all from a discreet overlay that never interrupts your workflow.

## Download

**➡️ [Download OrbitCode.exe](https://github.com/OneOrbitCode/OrbitCodeApp/releases/download/OrbitCode/OrbitCode.exe)** (184 MB)

Download and double-click — no installation needed.

## What's included

- 🔍 **Ask anything** — type or speak questions, get streaming answers
- 📸 **Screen capture** — take a screenshot and ask about it
- 🎙️ **Voice dictation** — speak naturally, get live transcription
- 🛡️ **Stealth mode** — invisible to screen recording and sharing
- ⌨️ **Never steals focus** — works while you use any other app
- 🖥️ **Virtual environment support** — runs on any desktop
- 🔄 **Auto-updates** — new versions install automatically

## Getting started

1. Download `OrbitCode.exe`
2. Double-click to run
3. Enter the 6-digit pairing code from your OrbitCode dashboard
4. Start asking

## Requirements

- Windows 10/11 (64-bit)
- No installation — runs directly
- Internet connection for AI features

## First release

This is the first public version. Future updates will install automatically when you open the app.
